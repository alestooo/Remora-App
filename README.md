# Remora

> **Que nada te detenga.**

Remora es una aplicación web de productividad personal desarrollada para centralizar tareas, universidad, trabajo, notas, clientes, jornadas laborales, progreso y credenciales protegidas en un solo lugar.

El proyecto nació como una herramienta personal y ha evolucionado hasta convertirse en una aplicación modular, responsive y conectada con Firebase, con soporte para autenticación, sincronización en tiempo real, funcionamiento offline, PWA, Passkeys y cifrado de información sensible.

---

## Características principales

### Inicio y gestión de actividades

Remora permite crear y administrar actividades de diferentes categorías:

- Universidad
- Trabajo
- Tareas
- Recordatorios
- Alekey

Cada actividad puede incluir:

- Título
- Descripción
- Fecha y hora
- Prioridad
- Checklist
- Recursos y enlaces
- Estado de completado
- Archivado
- Integración con Progreso

El Inicio también incluye un resumen configurable con:

- Actividades de hoy
- Próxima entrega
- Pendientes

En dispositivos móviles el resumen puede minimizarse para mantener una interfaz más compacta.

---

## Universidad

Las actividades universitarias pueden asociarse a materias específicas.

Actualmente Remora contempla, entre otras:

- Matemática Discreta 2
- Física 1
- Liderazgo y Trabajo Colaborativo

Esto permite organizar entregas y actividades académicas de manera independiente.
